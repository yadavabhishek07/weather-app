# Weather App

A fast, real-time weather forecasting web application that delivers live meteorological conditions for any city worldwide using the OpenWeatherMap API.

---

## Features

- **Live Weather Lookup**: Instant temperature, humidity, and atmospheric conditions by city name.
- **Dynamic Weather Emojis**: Visual icons adapting automatically to the returned weather conditions.
- **Error Handling**: Friendly alerts and fallbacks for invalid city names or network issues.
- **Clean Responsive UI**: Lightweight card layout styled with custom CSS and gradient aesthetics.

---

## Tech Stack

- **HTML5**: Form controls and layout structure.
- **CSS3**: Responsive flexbox card styling and typography.
- **JavaScript (ES6+)**: Async/Await API fetching and DOM rendering.
- **API**: OpenWeatherMap REST API.

---

## Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/yadavabhishek07/weather-app.git
cd weather-app
```

### 2. Run the application
Open `index.html` in any web browser. Enter a city name (e.g. *London*, *Delhi*, *New York*) and press **Get Weather**.
